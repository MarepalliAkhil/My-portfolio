# Planet textures (optional, recommended)

The page works without any files in this folder: every planet then gets a surface that is generated on your
graphics card the first time it is needed. For photographic planets, download the free 2k textures from
**Solar System Scope** (https://www.solarsystemscope.com/textures/, licence CC BY 4.0) and save them here with
exactly these file names:

| File                         | Used for                                  |
|------------------------------|-------------------------------------------|
| `2k_sun.jpg`                 | Sun                                       |
| `2k_mercury.jpg`             | Mercury                                   |
| `2k_venus_surface.jpg`       | Venus                                     |
| `2k_earth_daymap.jpg`        | Earth (falls back to a public CDN copy)   |
| `2k_mars.jpg`                | Mars                                      |
| `2k_jupiter.jpg`             | Jupiter                                   |
| `2k_saturn.jpg`              | Saturn                                    |
| `2k_saturn_ring_alpha.png`   | Saturn's rings                            |
| `2k_uranus.jpg`              | Uranus                                    |

The credit line "Textures: Solar System Scope (CC BY 4.0)" is already shown in the page footer. Keep it.
Missing files are simply skipped (you may see harmless 404 lines in the browser console).
