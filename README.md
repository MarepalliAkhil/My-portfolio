# Akhil Marepalli Portfolio

A scroll-controlled 3D solar-system portfolio. You start in deep space looking at the Sun, scroll down to fly
past it and on to each planet, and scroll up to fly back along the same route. At every planet, thin glowing
threads grow out of the planet's edge and end at cards holding that section's information.

| Planet  | Section        |
|---------|----------------|
| Sun     | Introduction   |
| Mercury | About me       |
| Venus   | Skills         |
| Earth   | Projects       |
| Mars    | Education      |
| Jupiter | Experience     |
| Saturn  | Certifications |
| Uranus  | Contact        |

## What this project is made of

* One page: `index.html` (HTML + CSS + JavaScript in a single file). **No framework, no npm packages, no build step,
  no environment variables, no secrets.** That is why there is no `package.json`, lockfile or `.env.example`.
* 3D engine: **three.js r128**, downloaded when the page opens (see "Offline use"). Fonts: Google Fonts.
* `resume.pdf`: behind the "Download resume" button. Replace it with your own PDF (keep the name).
* `textures/`: optional planet photos, see `textures/README.md`.
* `docs/earth-reference.jpg`: the reference photo the framing was based on (not used by the page).
* `.nojekyll`, `.gitignore`, `push-to-github.bat` / `push-to-github.sh`: deployment helpers.

## Why it no longer freezes

* The page paints first and starts the 3D engine in small steps, so the browser never sits on one long job.
* The 3D engine is downloaded **without blocking** the page, with several backup addresses and time limits.
* Planet surfaces are generated on **background threads**, sharp ones after quick soft ones. The graphics card is
  never given one huge program to compile (that was the cause of freezes on many Windows laptops).
* If your browser says 3D would run in slow software mode, or WebGL is missing, the page shows a **simple view**
  (the same cards around a glowing orb) instead of locking up. Add `?force3d=1` to the address to try 3D anyway.
* Resolution adapts automatically, drawing slows when nothing moves, and everything stops in a hidden tab.

## 1. What you need

* A recent desktop browser: Chrome, Edge, Firefox or Safari.
* **One** of these to run a tiny local web server: Python 3.8+ (python.org) **or** Node.js 18+ (nodejs.org).
* Optional: Visual Studio Code. Optional: Git (to push to GitHub).

Do not just double-click `index.html`; use the local server below.

## 2. Run it locally

Extract the ZIP, open the folder in VS Code (**File > Open Folder**), open a terminal (**Terminal > New Terminal**) and run:

Windows: `py -m http.server 8000`   |   macOS / Linux: `python3 -m http.server 8000`   |   Node: `npx --yes serve .`

Open **http://localhost:8000** (with `serve`, use the address it prints, normally http://localhost:3000).
Stop with `Ctrl + C`. If you extracted the ZIP into a parent folder, open `http://localhost:8000/akhil-marepalli-portfolio/`.

## 3. Production build

There is no build step; these files are the production version. Preview them with the same server command.
Check: scroll down (deep space, Sun, then each planet), cards and threads appear and retract, scroll up retraces the
route, a card opens a detail sheet, and F12 > Console shows no red errors (404 lines for missing textures are harmless).

## 4. Put it on GitHub (repository "My portfolio") and publish it

1. On github.com click **New repository**. Name it `My portfolio` (GitHub stores it as `My-portfolio`). Leave it empty
   (no README, no .gitignore). Create it.
2. In the project folder, run the helper: **Windows** double-click `push-to-github.bat`; **macOS/Linux**
   `sh push-to-github.sh`. Sign in to GitHub when asked. (It runs the normal `git init / add / commit / push` commands.)
3. In the repository open **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, Save.
4. After a minute the site is live at **https://marepalliakhil.github.io/My-portfolio/**.

Other free hosts: Netlify (drag the folder to https://app.netlify.com/drop) or Vercel (framework "Other", no build
command, output directory `.`).

Before sharing the link: set the Google Drive certificate folder to "Anyone with the link" and make the GitHub
repositories linked from the Projects planet public.

## 5. Customise

Everything is in `index.html`: card text lives in the `<div class="card" ...>` blocks (the part in `<div class="more" hidden>`
is the detail sheet); planets are in the `var P=[ ... ]` list; scroll length per planet is `var SEG=1.2`; thread look is
the `.th-c` and `.th-h` CSS rules.

## 6. Offline use and photo textures

* To avoid downloading the 3D engine, save `https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js` as
  `three.min.js` next to `index.html`. The page tries that local file first.
* Planets are generated by the page. For photographic planets add the free Solar System Scope textures listed in
  `textures/README.md` (CC BY 4.0, credit already in the page footer).
